# ShopGuard – Enterprise Hybrid Test Automation Framework

An enterprise-ready automation testing solution covering UI (Web) and RESTful API test suites with full reporting and failure analysis.

## Tech Stack
- Java 17
- Selenium WebDriver 4.24.0
- REST Assured 5.5.0
- TestNG (DataProvider & Listeners)
- Page Object Model (POM)
- Apache Maven

## Execution
mvn test
